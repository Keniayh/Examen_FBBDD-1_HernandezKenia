# Examen FBBDD 1 - Los Olímpicos

## Descripción

Proyecto de diseño de una **base de datos para la gestión de espacios deportivos relacionados con los Juegos Olímpicos**.

El proyecto parte del análisis de requisitos y desarrolla diferentes etapas de modelado hasta llegar a una estructura de base de datos normalizada.

## Proceso

- Análisis de requisitos.
- Modelo conceptual.
- Modelo lógico.
- Modelado UML.
- Normalización de la base de datos.
- Diseño de la estructura relacional.

## Herramientas

- **MySQL**
- **MySQL Workbench**
- **Lucidchart**
- **draw.io**

El proyecto fue desarrollado como ejercicio de fundamentos de bases de datos.
